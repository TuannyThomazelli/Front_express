# 🚀 Atividade Prática (Aula 04): Consumo e Criação de APIs REST

Repositório dedicado ao desenvolvimento das atividades da **Aula 04** da disciplina **Frameworks Front-end** no **SENAI**, sob orientação do **Prof. Me. Deivison S. Takatu** (`deivison.takatu@edu.senai.br`).

---

## 📌 Objetivos da Atividade


* Criar uma API REST em **Node.js** com **Express** e **CORS** para disponibilizar uma rota de consulta de data e hora atualizados.
* Realizar o deploy da API na plataforma de nuvem **Render**.
* Criar uma aplicação Front-end em repositório separado para consumir a API e exibir os dados na interface.
* Realizar o deploy do Front-end na **Vercel**.

---

## 🛠️ Tecnologias Utilizadas

* **Back-end:** Node.js, Express.js
* **Front-end:** JavaScript / Framework Front-end, Fetch API
* **Hospedagem & Deploy:** Render (API) e Vercel (Front-end)
* **Versionamento:** Git e GitHub
